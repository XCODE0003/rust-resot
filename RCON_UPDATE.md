# Обновление системы RCON и онлайна

## Изменения

### 1. Постоянные RCON-соединения
- Создан `RconConnectionManager` для управления постоянными WebSocket соединениями
- Теперь для каждого сервера создается одно постоянное соединение, которое переиспользуется
- Автоматическое переподключение при разрыве соединения
- Таймаут неактивности: 9 минут (540 секунд)
- Максимум 3 попытки переподключения при ошибках

### 2. Хранение онлайна в базе данных
- Создана новая таблица `server_online_data` для хранения данных об онлайне
- Удалено кеширование онлайн-данных (`Cache::forever`)
- Данные обновляются каждую минуту через cron задачу
- Статус сервера определяется автоматически: если данные обновлялись менее 2 минут назад - сервер Online

### 3. Оптимизация выдачи товаров
- Убраны повторные подключения при выдаче товаров (Shopping)
- Все команды отправляются через постоянное соединение
- Убраны блокировки через кеш (`transferServiceGameServer_lock`)
- Выдача товаров происходит сразу, без проверки онлайна игрока

### 4. Обновленные файлы

#### Новые файлы:
- `app/Services/RconConnectionManager.php` - менеджер постоянных соединений
- `app/Models/ServerOnline.php` - модель для таблицы онлайна
- `database/migrations/2026_03_13_000001_create_server_online_data_table.php` - миграция
- `app/Console/Commands/InitServerOnlineData.php` - команда инициализации

#### Измененные файлы:
- `app/Lib/RustCON.php` - использует RconConnectionManager
- `app/Console/Kernel.php` - переписаны задачи cron
- `app/Helpers.php` - функции online_count, online_max, online_queued, server_status читают из БД
- `app/Lib/RustGameApi.php` - методы getOnlineCount, getPlayersOnline, sendServiceToGame обновлены
- `app/Lib/GameServer/GameServerType1.php` - методы онлайна читают из БД
- `app/Http/Controllers/Api/ServersWipeController.php` - удалено кеширование

## Установка

1. Запустить миграцию:
```bash
php artisan migrate
```

2. Инициализировать данные:
```bash
php artisan server:init-online-data
```

3. Перезапустить cron задачи:
```bash
php artisan schedule:work
```

## Как это работает

1. **Каждую минуту** (everyMinute):
   - Для каждого сервера создается/переиспользуется постоянное WebSocket соединение
   - Отправляется команда `status` для получения онлайна
   - Данные парсятся и сохраняются в таблицу `server_online_data`
   - Проверяются неотправленные товары (Shopping) и отправляются через то же постоянное соединение

2. **Получение данных**:
   - Функции `online_count()`, `online_max()`, `online_queued()` читают данные из таблицы `server_online_data`
   - Функция `server_status()` определяет статус по времени последнего обновления (если < 2 минут - Online)

3. **Выдача товаров**:
   - Все команды отправляются через постоянное соединение
   - Нет повторных подключений
   - Блокировки только на уровне задачи Shopping (не на уровне RCON)

## Преимущества

- Нет постоянных новых подключений - меньше нагрузка на сервер
- Нет блокировок от игрового сервера
- Данные всегда актуальные (обновляются каждую минуту)
- Нет проблем с кешем (данные в БД)
- Более надежная система переподключения
- Улучшенное логирование
